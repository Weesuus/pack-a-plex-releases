# Pack a Plex

App Android per guardare i film e le serie di un server Plex. Questo repository contiene solo le versioni da installare, non il codice.

## Installazione

1. Dal telefono, scarica l'ultima versione: [PackAPlex.apk](https://github.com/Weesuus/pack-a-plex-releases/releases/latest/download/PackAPlex.apk).
2. Aprila e, se Android lo chiede, consenti l'installazione di app da questa fonte.
3. Entra con il tuo account Plex.

## Aggiornamenti

Quando esce una versione nuova, l'app la segnala in cima alla home: tocca **Aggiorna** e conferma l'installazione.
Puoi controllare anche da **Impostazioni**, in fondo alla pagina.
